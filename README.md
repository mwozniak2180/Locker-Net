# Locker-Net

Projekt zespołowy z przedmiotu **Sztuczna inteligencja w przetwarzaniu geodanych** (geoinformatyka, I stopień).

- **Zespół:** Mateusz Woźniak mwozniak2180, Jakub Wrzosek j-wrzosek
- **Temat:** Optymalizacja lokalizacji automatów paczkowych z wykorzystaniem grafowych sieci neuronowych (GNN).
- **Obszar:** Kraków

## Pytanie

Gdzie w Krakowie zlokalizować nowe automaty paczkowe?

## Struktura repozytorium

| Folder | Zawartość |
| --- | --- |
| `docs/` | karta projektu, przegląd literatury, plan pracy, karta danych, raport |
| `notebooks/` | notatniki Colab, numerowane w kolejności uruchamiania |
| `src/` | funkcje używane w kilku notatnikach |
| `data/` | dane pobierane kodem; nie trafiają do repozytorium |
| `wyniki/` | mapy, wykresy i małe warstwy wynikowe, do ok. 10 MB |
